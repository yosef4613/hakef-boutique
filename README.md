# הכיף שבאפיה — Hakef Boutique

מאגר עצמאי לעיצוב ובניית האתר החדש של **הכיף שבאפיה**, קייטרינג בוטיק ובר פטיפורים.

## האתר החדש — נואר 2.0 (`site/`)

[פתיחת האתר החדש](https://yosef4613.github.io/hakef-boutique/site/): בוטיק לבר פטיפורים ועוגות מפוארות, בלי אלמנטור. HTML/CSS/JS נקי, בלי ספריות, מוכן להפוך לתבנית וורדפרס.

איך מיושמים 5 הכללים מהסרטון "I Studied 10,000 AI Websites":

1. **מבחן המראה:** המסך הראשון עונה למי (שמחות בירושלים והסביבה), מה מקבלים (בר פטיפורים ועוגות מפוארות, בלי דאגות) ומה עושים עכשיו (כפתור אחד).
2. **כלל המרקר (60-30-10):** פחם 60%, שמנת 30%, וזהב שמפניה 10% **רק** על כפתורים וקישורים.
3. **רקע · אמצע · חזית:** צילום אמיתי ברקע, טקסט באמצע, כפתור עם צל בחזית. תמונת הבר "שוברת את הקצה" לחלק הבא.
4. **תנועה עם תפקיד:** במסך הראשון אין אנימציה בכלל. למטה: כרטיסים נערמים (מראים את המוצר), רצועת עוגות אופקית (מראה את המוצר), קו מתמלא ב"איך מזמינים" (מוביל את העין), מספר שמתעדכן במתכנן (מראה מה קרה). דבר אחד זז בכל מסך. יש מתג "תנועה" ותמיכה בהפחתת תנועה.
5. **דוגמה חינם:** מתכנן הבר: סוג אירוע, מספר אורחים ותפקיד הבר, ומתקבל הרכב מומלץ. הבקשה נשלחת לוואטסאפ של העסק עם כל הפרטים.

מדידה בטלפון מואט (4G איטי, מעבד פי 4): המסך הראשון מוכן תוך ~2 שניות ושוקל ~150KB. באתר הנוכחי: 8.5 שניות ו־3.9MB.

**לבדיקה מול בעלת העסק לפני השקה:**
- יחסי הכמויות במתכנן (`PLAN` בראש `site/assets/js/site.js`): כרגע 3 יחידות לאורח אחרי ארוחה ו־6 כשהבר הוא הכיבוד המרכזי, ועוגה מומלצת מ־50 אורחים.
- נוסח הכשרות ("כשרות מהודרת", מתוך תיאור האתר הקיים).
- סוגי האירועים בצ'יפים ובפס "לבר מצווה · לבת מצווה...".
- הצהרת נגישות (חובה לפני השקה על hakef.com).
- התמונות נלקחו מהאתר הקיים: ממוזערות, חתוכות (בלי חותמות זמן של הטלפון ובלי אנשים) ושמורות במאגר.

### מבנה האתר ואיך מעדכנים

האתר נבנה מסקריפט אחד: `python3 build/build.py`. הוא יוצר 30 עמודים בתיקייה `site/`: דף בית, קטלוג, 4 קטגוריות, 19 מוצרים, עמוד "בר קינוחים לאירועים", אודות, צור קשר, נגישות ופרטיות. הוא יוצר גם `sitemap.xml`, `robots.txt` ו־`deploy/.htaccess`.

- **להוסיף או לשנות מוצר:** לערוך את `build/data/products.json`, לשים תמונה ב־`site/assets/img/` (בשם `שם-480.webp` / `שם-800.webp`) ולהריץ את הסקריפט.
- **דף הבית:** `build/pages/home.html`.
- **לאתר האמיתי:** `python3 build/build.py --production --out dist`. זה בונה ל־`dist/` בלי noindex, כולל `.htaccess`, ואת `dist/` מעלים לשורש של hakef.com.
- כתובות המוצרים והקטגוריות זהות לאתר הישן, כדי לשמור על הדירוג בגוגל.

### מתכונים ואזור ניהול (וורדפרס)

וורדפרס נשאר באתר רק לשני דברים: ממשק הניהול, ועמודי המתכונים (`/מתכונים/`). כל שאר האתר הוא קבצים סטטיים.

- `wp/mu-plugins/hakef-recipes.php`: סוג התוכן "מתכון", מסך הוספה פשוט, תפקיד "עורכת מתכונים" עם תפריט מצומצם, ומפת אתר למתכונים בלבד.
- `wp/mu-plugins/hakef-seed-recipes.php` ו־`hakef-seed/recipes.json`: ייבוא חד־פעמי של 5 המתכונים מהאתר הישן, אחרי ניקוי ותיקון כתיב.
- `wp/themes/hakef/`: התבנית. את `header.php` ו־`footer.php` הסקריפט מייצר, כך שהם זהים לשאר האתר.

**איך מוסיפים מתכון:** נכנסים ל־`hakef.com/wp-admin`, ובוחרים "מתכונים" ואז "מתכון חדש".
1. כותבים שם ובוחרים תמונה.
2. ממלאים מצרכים, שורה לכל מצרך. שורה שמסתיימת בנקודתיים, למשל "לקרם:", הופכת לכותרת.
3. ממלאים אופן הכנה, שורה לכל שלב.
4. זמן, כמות וטיפ אינם חובה.
5. לוחצים "פרסום". העיצוב והסימון לגוגל נעשים לבד, ומתכון בלי תמונה מקבל כריכה מעוצבת.

**העלייה לאוויר:** כל ההכנות בשרת בוצעו: גיבוי מלא, תבנית ומתכונים מותקנים, והתוספים והתבניות הישנים נמחקו. המצב המעודכן וצעדי העלייה כתובים ב־[deploy/GO-LIVE.md](deploy/GO-LIVE.md), ומבוצעים עם `deploy/golive.sh`. אפשר לחזור אחורה עם `deploy/rollback.sh`.

מדריך הקידום המלא: [docs/SEO.md](docs/SEO.md). **מה שנשאר לעשות בקידום, צעד אחר צעד:** [docs/רשימת-משימות-קידום.md](docs/רשימת-משימות-קידום.md).

## הגדרת פרסום GitHub Pages

להפעלת הקישורים בפעם הראשונה, במאגר GitHub:
**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.

הדוגמאות (noir, ivory וכו') הן הדמיה בלבד: טפסי ההזמנה בהן אינם שולחים מידע לשרת, והתמונות שלהן נטענות מהאתר הפעיל ב־hakef.com. האתר החדש ב־`site/` מחזיק את התמונות שלו בתוך המאגר.

לא בוצעו שינויים באתר הקיים ב־Hostinger. אין במאגר פרטי כניסה או סודות.
